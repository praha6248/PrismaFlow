PrismaFlow runs on your computer. Text is generated by a local model in Ollama, so your data stays on your disk.

Before the first launch:

1. Install Ollama
   https://ollama.com/download
   After installation Ollama runs in the background (tray icon).

2. Download the main model (open PowerShell or Command Prompt):
   16 GB RAM or more:   ollama pull gemma3:12b    (8.1 GB)
   Less than 16 GB:     ollama pull gemma3:4b     (3.3 GB)
   Source: https://ollama.com/library/gemma3

3. Optional, better evidence search:
   ollama pull bge-m3    (1.2 GB)
   Source: https://ollama.com/library/bge-m3

4. Optional, UX fine-tuned model for the Deliver phase:
   see the "Models" section on the GitHub release page.

PrismaFlow checks all of this on start and shows the missing steps.
You can also skip local models and use the quality mode with your own Claude API key.

PrismaFlow needs Microsoft Edge WebView2, which is part of Windows 10 and 11.
If the window stays blank, install it from https://developer.microsoft.com/microsoft-edge/webview2/

PrismaFlow działa na Twoim komputerze. Tekst generuje lokalny model w Ollamie, więc dane zostają na dysku.

Przed pierwszym uruchomieniem:

1. Zainstaluj Ollamę: https://ollama.com/download
2. Pobierz główny model:
   16 GB RAM lub więcej:  ollama pull gemma3:12b
   Mniej niż 16 GB:       ollama pull gemma3:4b
3. Opcjonalnie: ollama pull bge-m3 (lepsze wyszukiwanie dowodów)
4. Opcjonalnie: model dostrojony do UX, opis na stronie wydania na GitHubie.

PrismaFlow sprawdza to przy starcie i pokazuje brakujące kroki.
