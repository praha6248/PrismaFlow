# Good first issues

Ready-to-file ideas for newcomers. Label them `good first issue` when creating them on GitHub.

1. Add an English translation of the UI strings and a language switch.
2. Add a new community collector for a documented public API (for example Hacker News via Algolia).
3. Add a Markdown export of the Discover mind map and its evidence.
4. Export the Develop backlog as CSV.
5. Add a locale (for example `de_DE`) to the Autocomplete and Trends collectors.
6. Show collector errors (which source failed and why) in the UI instead of only in logs.
7. Add keyboard shortcuts for common canvas actions in Deliver.
8. Add tests for the Hick and Fitts formulas with edge cases (empty lists, one option).
9. Document how to pick and benchmark a different Ollama model in the README.
10. Add a dark theme using the existing colour tokens.
11. Add an architecture diagram image to `docs/`.
12. Record a short demo GIF of the full Discover to Deliver flow for the top of the README.
